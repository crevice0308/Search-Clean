# Search-Clean

**Search Clean Lite** — Google検索の「AIによる概要」を、ブラウザー上で非表示にする拡張機能です。ポップアップのスイッチからON／OFFを切り替えられます。

> 現在は **1.0.0 プレリリース**です。Chromeウェブストア・Microsoft Edge Add-onsでの審査済み製品ではありません。

## ダウンロード

- **[Search-Clean-Lite-1.0.0.zip をダウンロード](https://github.com/crevice0308/Search-Clean/releases/download/v1.0.0-preview.1/Search-Clean-Lite-1.0.0.zip)**
- [プレリリースの詳細・検証状況](https://github.com/crevice0308/Search-Clean/releases/tag/v1.0.0-preview.1)

インストールには上記ZIPを使用してください。GitHubが自動生成する「Source code (zip)」とは別のファイルです。

## 対象

Windows版のGoogle Chrome／Microsoft Edgeで、展開した拡張機能として読み込む手順を案内しています。すべてのOS・ブラウザーバージョンでの動作を保証するものではありません。

対象ページは、次のホストのHTTPS検索ページ（`/search`、検索パラメーター付きも含む）です。

- `www.google.com` / `google.com`
- `www.google.co.jp` / `google.co.jp`

Manifest V3を使用し、マニフェスト上のChrome最低バージョンは105です。これは最低要求の宣言であり、その全バージョンでの実機検証済みという意味ではありません。

## インストール（Windows）

1. 上記ZIPをダウンロードし、右クリック → **すべて展開**で解凍します。
2. 解凍したフォルダーを、使用中に移動・削除しない保存場所へ置きます。
3. 拡張機能の管理画面を開きます。
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
4. **デベロッパーモード**（開発者モード）をONにします。
5. **パッケージ化されていない拡張機能を読み込む**／**展開して読み込み**を選択します。
6. 次の **`extension` フォルダー**を指定します。ZIPそのものや、その親フォルダーではありません。

```text
Search-Clean-Lite-1.0.0/
└── extension/       ← このフォルダーを選択
    ├── manifest.json
    ├── content.js
    └── …
```

7. Google検索ページを再読み込みします。必要なら拡張機能をツールバーへ固定してください。

**読み込んだ `extension` フォルダーは使用中に移動・削除しないでください。** アンインストールは拡張機能の管理画面で「削除」を選び、その後に保存フォルダーを削除します。

## 使い方

ツールバーの **Search Clean Lite** を開き、スイッチを切り替えます。

- **ON（初期設定）**：対象の「AIによる概要」を非表示にします。
- **OFF**：拡張機能による非表示を解除します。

Google側が概要を出さない検索もあります。OFFにしても概要が出ない場合、それだけでは拡張機能の成否を判定できません。

## 仕組み・権限・プライバシー

- CSSによる**表示の非表示化**です。AI概要の生成や通信、Google側のデータ収集を止める機能ではありません。
- `storage` 権限を使用し、ON／OFF設定を `chrome.storage.local` に保存します。
- コンテンツスクリプトの実行対象は上記のGoogle検索ページです。
- 配布コードの静的確認では、検索内容の外部送信や解析用通信を行う処理は見つかっていません。ただし、これは包括的なセキュリティ監査やブラウザー全体の通信検証ではありません。

## 検証状況と注意点

- 静的確認・モック環境のテスト **41件が成功**しています。
- ユーザー環境では「AIによる概要が非表示になった」との動作報告があります。
- 独立した実Google検索環境でのON／OFF比較、長期動作、各ブラウザーでの互換性確認は未完了です。モックテストの成功は実サイトでの完全な動作保証ではありません。
- Googleの画面構造変更や表示パターンによって、非表示にできない場合や意図しない箇所へ影響する場合があります。問題があればOFFにするか、拡張機能を無効化してください。

不具合は [Issues](https://github.com/crevice0308/Search-Clean/issues) へ、ブラウザーの種類・バージョン、再現手順、ON／OFF時の違いを添えてお知らせください。検索語やスクリーンショットに個人情報を含めないようご注意ください。
